# 报销审核权限

报销审核页只展示当前业务身份负责的待办。侧栏入口、状态筛选、行内操作、批量操作及 API 状态流转共用 `src/lib/permissions.ts` 中的审批节点定义。

| 身份 | 可见待办 | 推进操作 |
| --- | --- | --- |
| 管理员（admin）、管理人员（manager） | 已提交待审核 | 审核通过 → 已审核待复核 |
| 财务（finance） | 已审核待复核、已确认待执行 | 复核通过 → 已复核待确认；确认已执行 → 已执行 |
| 老板（owner） | 已复核待确认 | 确认报销 → 已确认待执行 |
| 员工（executor、designer、planner） | 不显示报销审核入口 | 无审核权限，直接访问页面跳转，审核 API 返回 403 |

审核、复核和确认节点支持由当前负责身份打回并填写原因；执行节点不支持打回。批量处理遵循相同限制。管理员不再跨节点推进、打回其他身份负责的记录。

普通审核者不得审核本人报销。系统保留固定管理员 UID 使用额外业务身份验证流程的既有机制，但始终按当前业务身份决定可操作节点。
